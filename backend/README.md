# Robert & Izak Computers - WhatsApp Backend Service

Backend service for WhatsApp integration with Robert & Izak Computers customer service platform.

## Features

- 🤖 WhatsApp Web integration using `whatsapp-web.js`
- 🔄 Real-time messaging via Socket.IO
- 💾 Message persistence with Supabase
- 📱 Automatic ticket creation from WhatsApp messages
- 👥 Multi-client support
- 🔐 Secure API with rate limiting
- 📊 Conversation history and tracking

## Prerequisites

- Node.js >= 18.0.0
- npm or yarn
- Supabase account and database
- WhatsApp account (for business use)
